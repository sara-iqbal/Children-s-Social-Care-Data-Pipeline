Children's Social Care Performance Dashboard

Reporting year 2025-26 for two fictional borough services. Built from a Python and SQL pipeline that generates case data, validates it, produces an SSDA903-style statutory return and calculates a performance scorecard.

How it was built

01GeneratePython creates linked tables for children, referrals, assessments, CP plans, care episodes and care leavers, with realistic patterns and planted errors.
02ValidateTen SQL rules modelled on DfE checks produce an exceptions report by rule, team and worker.
03ReturnHeader, Episodes and OC3 tables are built in the SSDA903 layout, with children who have blocking errors flagged.
04ReportEight standard KPIs with targets and RAG ratings, exported to CSV for Power BI and JSON for this page.
Built by Sara Iqbal with Python, SQL (SQLite), Power BI and Chart.js. Data generated with a fixed random seed, so every run reproduces the same figures.
